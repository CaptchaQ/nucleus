# interview — интервью перед стартом проекта

Проводится **агентом в чате с человеком**. Человек отвечает словами —
никаких форм, CLI-скриптов и анкет. Твоя задача — задавать вопросы по
одному, слушать и фиксировать.

## Когда применять

- Начинается новый проект (папка пустая или почти пустая).
- В папке нет `.agent-forge/profile.json`.
- Человек сказал «создай проект», «начнём новый проект», «сделай X».

## Правила

1. **Один вопрос за раз.** Задал вопрос — жди ответа. Следующий вопрос
   только после ответа на предыдущий.
2. **Рекомендация вместо пустоты.** Если человек не знает ответа —
   предложи рекомендацию из списка вопросов. Если он согласен — записывай.
3. **Факты — сам, решения — человек.** Технические детали, которые можно
   проверить (версии, совместимость), не спрашивай — узнай сам.
4. **Не начинай код до конца интервью.** Профиль — контракт.
5. Если человек отвечает «не знаю» на вопрос о стеке — предложи
   популярный безопасный вариант и отметь это в профиле как рекомендацию.

## Вопросы (по порядку)

Задавай строго по порядку. Пропускать можно только вопросы, нерелевантные
домену (домен становится известен после вопроса 3).

1. **name** — «Как называется проект? Одно-два слова.»
   Рекомендация: имя папки.

2. **destination** — «Что значит „дойти до конца"? Опишите destination
   одной-тремя строками — что должно появиться в итоге.»
   Подсказка: destination фиксирует scope; всё за его пределами — out of
   scope.

3. **domain** — «К какой области относится проект?»
   Варианты: `web`, `ui`, `backend`, `fullstack`, `data`, `ml`, `cli`,
   `mobile`, `infra`, `content`.
   Рекомендация: `fullstack`.

4. **languages** — «На каких языках пишем? Перечислите основные.»
   (для web/backend/fullstack/data/ml/cli/mobile/infra)
   Рекомендация: `typescript`.

5. **frameworks** — «Фреймворки, рантаймы, ключевые библиотеки?»
   (для web/ui/backend/fullstack/data/ml/mobile)
   Пример: React + Node, FastAPI, Next.js.

6. **harness** — «В каком агент-харнессе вы работаете?»
   Варианты: `claude-code`, `codex`, `cursor`, `opencode`, `gemini`, `zed`.
   Рекомендация: `claude-code`.

7. **tracker** — «Issue-трекер: GitHub Issues, Linear или локальные
   markdown-файлы?»
   Рекомендация: `github`.

8. **quality** — «Какие обратные связи у вас есть (статические типы,
   браузерный доступ, тесты, e2e)? Какие из них MUST быть?»
   (для web/ui/backend/fullstack/data/ml/mobile)

9. **out-of-scope** — «Что точно НЕ входит в этот проект? Что вы
   осознанно отсекаете?»
   Важно: запиши дословно, это защита от scope creep.

10. **glossary** — «Есть ли термины, которые агент должен знать заранее
    (предметная область, аббревиатуры)?»
    Подсказка: общий язык уменьшает многословность и экономит токены.

## Результат — profile.json

После последнего ответа создай `.agent-forge/profile.json` в корне проекта:

```json
{
  "name": "имя-проекта",
  "destination": "одна-три строки: что должно появиться",
  "domain": "fullstack",
  "languages": ["typescript"],
  "frameworks": ["react", "node"],
  "harness": "claude-code",
  "tracker": "github",
  "quality": "тесты, типы",
  "outOfScope": ["мобильное приложение"],
  "glossary": {
    "термин": "определение"
  }
}
```

Правила записи:

- `languages` / `frameworks` — массивы; если человек перечислил через
  запятую — разбей.
- `outOfScope` — массив; каждое отсечение отдельным элементом.
- `glossary` — объект термин → определение.
- Если какой-то ответ не получен — оставь поле пустым, НЕ выдумывай.

После сохранения покажи человеку итог одним экраном:

```
Профиль зафиксирован:
  destination: <...>
  domain: <...>
  стек: <...>
  вне скоупа: <...>
```

Затем передай управление скилу `plan` (декомпозиция на этапы).
