# nucleus-skill-add

The **extensibility loop** of nucleus: "изучи и добавь скилл — создай
пространство под него и обнови документацию." When the user points the agent
at a new skill (a URL, a repo, a folder, or a bare idea), the agent:

1. **Studies** the source — reads the SKILL.md / README, extracts the purpose,
   the when-to-use, and how it composes with what's already loaded.
2. **Scaffolds** a space for it at `.agent-forge/skills/<name>/SKILL.md`.
3. **Documents** it — registers it in the catalog and updates the README table
   of loaded skills.

## Run it

```bash
# Scaffold a fresh skill (then edit SKILL.md):
nucleus skill add <name>

# or, for a skill you already have a source for, copy it in:
nucleus skill add <name>
# then fill the generated SKILL.md from your source material
```

## The .agent-forge/skills/ contract

Every custom skill lives at `.agent-forge/skills/<name>/` and MUST contain a
`SKILL.md`. It's an **overlay** skill — versioned by the repo itself, discovered
by the loader automatically:

```
.agent-forge/skills/
  my-domain-skill/
    SKILL.md
    references/        # optional supporting material
    examples/          # optional worked examples
```

## After adding a skill

1. **Reindex** so the catalog and README stay in sync:

   ```bash
   npm run reindex
   ```

2. **Confirm it's visible:**

   ```bash
   nucleus catalog
   ```

   Overlay skills are listed under "Overlay skills in this repo".

3. If the skill should live on a specific subagent, add its id to the
   `ROLE_BY_SKILL` table in `src/orchestrator/runner.ts` — `nucleus orchestrate`
   then routes it to the right agent role with no further wiring.

## Rules

- **The user's skill owns the space.** Never overwrite an existing
  `.agent-forge/skills/<name>/SKILL.md` without asking.
- **Frontmatter is required.** At minimum `name` and `description`; `name`
  should match the folder (lowercase kebab).
- **One source → one skill.** If the source is a multi-skill repo, split into
  one folder per skill rather than bundling.
- **Keep the docs honest.** Every skill you add shows up in the catalog; the
  README's "Loaded skills" table is regenerated by `npm run reindex`.
