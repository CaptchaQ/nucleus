# improve — итеративная доработка

Когда человек говорит «сделай лучше», «почини это», «докрути» — не
переписывай с нуля и не «улучшай вслепую». Работай циклом: **вариант →
проверка → решение**.

## Когда применять

- Доработка существующего кода, README, промптов, копирайта.
- Обратная связь: «не нравится», «медленно», «не читается», «баг».
- Полировка перед сдачей этапа.

## Цикл улучшения

Повторяй, пока критерий не выполнен (обычно 1–3 итерации):

1. **Зафиксируй критерий.** Что значит «лучше»? Одна строка: «заголовок
   продаёт за 5 секунд», «запрос < 200 мс», «нет дублирования кода».
   Если критерия нет — спроси у человека, не выдумывай.
2. **Сгенерируй вариант.** Один осмысленный вариант, а не 5 черновиков.
   Вариант должен быть *другим* по существу, а не переставленными словами.
3. **Проверь вариант по критерию** (и по `profile.json` / `plan.md`):
   - код: запусти, прогони тесты/сценарий;
   - текст: прочитай глазами — критерий выполнен?
4. **Реши:** вариант лучше — прими; не лучше — откати и попробуй иначе;
   равнозначно — оставь как было (не меняй ради изменений).
5. **Зафиксируй результат** в `.agent-forge/improvements.md`:
   `файл | критерий | итерация | результат`.

## Правила

1. **Никогда не «улучшай» без критерия.** «Сделай красивее» — это не
   критерий. Уточни: что именно не так и как поймём, что стало лучше?
2. **Меняй по одной оси за раз.** Не смешивай «переписать заголовок» и
   «перекрасить всё» — результат станет непроверяемым.
3. **Код — через запуск.** Текст можно оценить глазами, код — только
   запуском. Нет запуска — нет уверенности.
4. **Откат — это ок.** Худший вариант — оставить непроверенное изменение.
   Вернись к рабочему состоянию и попробуй другой путь.
5. Артефакты проверяй на соответствие `profile.json` (стек, glossary,
   out-of-scope).

## Пример

```
Человек:  README скучный, сделай интереснее.
Агент:    Критерий: заголовок + первые 2 строки объясняют, зачем это,
          за 5 секунд чтения. Так?
Человек:  Да.
Агент:    (вариант заголовка и лида → проверка по критерию → принято)
          Зафиксировано в .agent-forge/improvements.md.
```
